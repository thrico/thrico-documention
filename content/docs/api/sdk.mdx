## Available SDKs

### 1. Thrico Enterprise Leaderboard SDK (`@thrico/leaderboard-sdk`)

A high-performance, zero-iframe client library for rendering real-time rankings, top performer podiums, and badge tiers directly in React, Next.js, Vue, Angular, or vanilla HTML/JS web applications.

#### Installation:

<Tabs items={['npm', 'pnpm', 'yarn', 'CDN']}>
  <Tab value="npm">
```bash
npm install @thrico/leaderboard-sdk
```
  </Tab>
  <Tab value="pnpm">
```bash
pnpm add @thrico/leaderboard-sdk
```
  </Tab>
  <Tab value="yarn">
```bash
yarn add @thrico/leaderboard-sdk
```
  </Tab>
  <Tab value="CDN">
```html
<script src="https://assets.thrico.network/leaderboard/v1/leaderboard.min.js"></script>
```
  </Tab>
</Tabs>

#### Quick Example:

```typescript
import { ThricoLeaderboardClient } from "@thrico/leaderboard-sdk";

const client = new ThricoLeaderboardClient({
  clientId: "thrico_client_YOUR_CLIENT_ID",
  endpoint: "https://sdk.thrico.network",
  autoRefreshIntervalMs: 30000, // Optional 30s auto-sync
});

// Fetch Top 3 for Podium
const { topEntries } = await client.getTopUsers("rewards_monthly_champions", { limit: 3 });

// Fetch Paginated Standings
const { entries, pagination } = await client.getEntries("rewards_monthly_champions", { page: 1, limit: 20 });
```

<Callout type="info">
  **Dashboard Administration**: Manage client credentials, whitelist domains (CORS), and generate instant embed widgets in the Thrico Admin Portal at `/gamification/points-and-badges/settings/leaderboard`.
</Callout>

### 2. Thrico Media Gallery SDK & Drop-in Uploader (`@thrico/media-gallery-sdk`)

A lightweight, zero-iframe client library and drop-in embed widget for uploading photos and videos directly into community albums with daily quota enforcement and pre-signed S3 direct uploads.

#### Installation:

<Tabs items={['npm', 'pnpm', 'yarn', 'CDN']}>
  <Tab value="npm">
```bash
npm install @thrico/media-gallery-sdk
```
  </Tab>
  <Tab value="pnpm">
```bash
pnpm add @thrico/media-gallery-sdk
```
  </Tab>
  <Tab value="yarn">
```bash
yarn add @thrico/media-gallery-sdk
```
  </Tab>
  <Tab value="CDN">
```html
<script src="https://sdk.thrico.network/gallery-uploader.min.js"></script>
```
  </Tab>
</Tabs>

#### Drop-in Widget Example:

```html
<div id="thrico-gallery-uploader"
     data-client-id="thrico_client_YOUR_KEY"
     data-title="Annual Alumni Gala 2026"
     data-subtitle="Share photos and videos directly with fellow attendees.">
</div>
<script src="https://sdk.thrico.network/gallery-uploader.min.js"></script>
```

#### Programmatic SDK Example:

```typescript
import { ThricoMediaGalleryClient } from "@thrico/media-gallery-sdk";

const gallery = new ThricoMediaGalleryClient({
  clientId: "thrico_client_YOUR_KEY",
  endpoint: "https://sdk.thrico.network",
});

// Upload a photo or video
const result = await gallery.uploadFile({
  file,
  caption: "Annual Gala opening ceremony",
  uploaderName: "Alex Smith",
  uploaderEmail: "alex@example.com",
  onProgress: (percent) => console.log(`${percent}% uploaded`),
});
```
