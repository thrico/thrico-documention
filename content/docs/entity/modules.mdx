# Module Management

## Overview

The **Module Management** console (`/settings/modules`) gives administrators full control over which ecosystem features are active, how they are named, whether they appear on Web or Mobile navigation, and in what order they display to members.

---

## Key Capabilities & Configuration

### 1. Enable / Disable Modules
Toggle features on or off according to your community's needs:
- **Core Modules**: Directory, Feed, Communities, Events, Learnings / Courses, Forums, Jobs, Marketplace / Offers, Polls, Moments, Mentorship, Gamification, and Wallet.
- Deactivating a module hides it from navigation bars and user interfaces without deleting underlying historical data.

---

### 2. Custom Module Renaming
Tailor platform terminology to match your brand language:
- Change **"Learnings"** → **"Academy"** or **"Masterclasses"**
- Change **"Gamification"** → **"Rewards Club"** or **"Loyalty Hub"**
- Change **"Communities"** → **"Chapters"** or **"Circles"**
- Change **"Feed"** → **"Town Square"**

---

### 3. Navigation Placement (Web vs. Mobile)
Control visibility across different platforms:
- **Show in Web Navigation**: Toggle whether the module appears in the desktop top/side navbar.
- **Show in Mobile Navigation**: Toggle whether the module is pinned to the mobile app bottom tab bar or hidden inside the "More" drawer.

---

### 4. Drag-and-Drop Tab Ordering
- Switch between **Web Navigation** and **Mobile Navigation** tabs.
- Drag modules up or down to rearrange the exact display order of tabs in member navigation.

---

### 5. Access & Visibility Policies
- **Public Facing**: Make the module accessible to visitors before login (great for SEO and lead generation).
- **Members Only**: Require active login or specific membership tiers to view.

---

## Step-by-Step Workflow to Update Modules:
1. Go to **Settings** → **Modules** (`/settings/modules`).
2. Toggle on/off desired modules.
3. Edit module labels if custom naming is desired.
4. Rearrange tab sequence via drag-and-drop.
5. Click **Save Changes** in the bottom floating save panel to apply updates instantly across Web and Mobile apps.
