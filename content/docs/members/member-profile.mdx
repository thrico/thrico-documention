# Member 360° Profile Hub

## Overview

The **Member 360° Profile Hub** (`/members/[id]/*`) provides administrators with an exhaustive single-pane-of-glass console detailing an individual member's entire lifecycle, contributions, permissions, and network footprint within the community.

---

## Profile Sub-Tabs Architecture

```
/members/[id]
 ├── Profile        → Overview of contact info, bio, social links, roles, and status
 ├── Edit           → Metadata editor, avatar upload, and role/tier overrides
 ├── Gamification   → Points ledger, unlocked badges, rank ascension history, and wallet
 ├── Stats          → Longitudinal session trends, login logs, and engagement scores
 ├── Communities    → Sub-community, channel, and chapter memberships
 ├── Events         → Registrations, check-in history, and ticket receipts
 ├── Feed & Content → Archive of posts, articles, comments, and media uploads
 ├── Forums         → Discussion threads authored and accepted answer solutions
 ├── Jobs & Listings→ Marketplace offerings, job postings, and applications
 ├── Polls & Moments→ Voting participation and media moment contributions
 └── Referrals      → Personal referral metrics, invite links, and converted peers
```

---

## Detailed Tab Breakdown

| Tab Name | Capabilities & Key Data Displayed |
| :--- | :--- |
| **Profile Overview** | Legal and display names, verified email, phone number, bio, headline, website/social handles, join date, last active timestamp, and account status tags. |
| **Edit Profile** | Form to update user profile attributes, avatar cropping, tier level assignment, custom metadata fields, and account suspension toggles. |
| **Gamification** | Total points balance, spendable currency balance, badge showcase, current rank tier progress bar, and comprehensive ledger of all credit/debit events. |
| **Stats & Analytics** | Active day counts, average weekly session duration, contribution velocity, and historical Impact Score radar breakdowns. |
| **Communities** | List of joined groups, chapters, and private spaces with role permissions (e.g., *Member, Moderator, Group Lead*). |
| **Events** | Comprehensive history of upcoming registrations, past attendance records, check-in timestamps, and purchased ticket tiers. |
| **Feed & Content** | Filterable stream of all feed posts, stories, articles, and rich media published by the member, with one-click moderation controls. |
| **Forums** | All initiated discussion threads, replies, upvotes received, and community-verified solutions. |
| **Jobs & Listings** | Marketplace products listed for sale, company jobs posted, and application submissions. |
| **Polls & Moments** | Historical voting decisions in community polls and photo/video moment submissions. |
| **Referrals** | Number of unique clicks generated by the member's referral link, confirmed registrations, tier upgrade conversions, and lifetime referral points earned. |
