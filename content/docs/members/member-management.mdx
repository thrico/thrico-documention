# Member Directory & Operations

## Overview

The **Member Directory** (`/members/all`) is the central control plane for browsing, filtering, inspecting, and executing administrative actions across all registered community members.

---

## Search & Filtering Capabilities

### Real-Time Search
- **Supported Fields**: Instant debounced search across Full Name, Username/Handle, Primary Email Address, Phone Number, and Custom Attributes.
- **Syntax**: Supports exact string matches and multi-word token queries.

---

### Multi-Dimensional Filters

| Filter Type | Options & Scope |
| :--- | :--- |
| **Account Status** | `Active`, `Pending Approval`, `Suspended`, `Archived`, `Unverified Email` |
| **Membership Tier** | `Free Tier`, `Silver Tier`, `Gold VIP`, `Founding Member`, Custom Tiers |
| **System Role** | `Super Admin`, `Entity Admin`, `Community Moderator`, `Member` |
| **Classification** | Chapter / Region, Cohort / Graduation Batch, Department, Industry |
| **Activity Level** | Active Last 7 Days, Inactive 30+ Days, High Spender, High Impact |

---

## Directory View Modes

### 📋 Table View
Optimized for high-density administrative operations.
- **Columns**: Selection Checkbox, Avatar & Display Name, Handle, Contact Email, Status Badge, Current Tier, Join Date, Engagement/Impact Score, and Actions Menu (`...`).
- **Sorting**: Click any column header to sort in ascending or descending order.

### 🎴 Card / Grid View
Tailored for showcase and directory browsing.
- **Highlights**: Large member avatars, cover banner accents, visual rank badges, public bio excerpts, location flairs, and direct message/profile action buttons.

---

## Bulk Operations

Perform batch actions across multiple selected members or entire filtered cohorts:

- **Bulk Tier Upgrade / Downgrade**: Change membership tier levels with automatic perk recalculations.
- **Bulk Messaging & Alerts**: Send targeted push notifications or email broadcasts to selected cohorts.
- **Bulk Status Modification**: Activate, suspend, or archive multiple accounts in a single confirmation step.
- **Bulk CSV / JSON Export**: Export custom datasets including profile fields, transaction counts, and contact records.
