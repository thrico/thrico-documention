# Member Classifications & Structuring

## Overview

The **Classification Subsystem** (`/members/classification`) provides multi-dimensional taxonomy tools to categorize and structure diverse member populations. It supports geographic chapters, time-bound cohorts, corporate departments, industry verticals, and flexible custom tags.

---

## Supported Classification Dimensions

| Dimension | Description | Common Use Cases |
| :--- | :--- | :--- |
| **Chapters & Regions** | Spatial or geographic groupings. | *San Francisco Hub, London Chapter, APAC Region* |
| **Cohorts & Batches** | Time-bound progression cohorts. | *Spring 2026 Batch, Class of '24, Beta Testers* |
| **Departments & Units** | Organizational or enterprise subdivisions. | *Engineering, Product Design, Executive Leadership* |
| **Industries & Verticals** | Professional domains and sectors. | *Healthcare, FinTech, SaaS, Education* |
| **Custom Tags** | Freeform tags for dynamic segmenting. | *Speaker, Mentor, Beta Tester, VIP Sponsor* |

---

## Creating & Managing Taxonomies

### Step 1: Define Taxonomy Schemas
- Set dimension names, icon badges, and hierarchical nesting rules (e.g., *Parent Region: North America → Child Chapter: New York*).

---

### Step 2: Member Assignment Rules
- **Manual Assignment**: Administrators can tag individual member profiles or apply tags during bulk CSV imports.
- **Self-Selection Onboarding**: Allow members to select their chapter or industry during initial registration.
- **Rule-Based Dynamic Tagging**: Automatically assign tags based on user actions (e.g., attending 5 events = *Active Attendee* tag).

---

### Step 3: Targeted Operations Using Classifications
- **Segmented Email Broadcasts**: Dispatch announcements exclusively to a specific chapter or graduation year.
- **Restricted Channels**: Provision private discussion groups automatically visible only to members with matching cohort tags.
- **Filtered Analytics**: Compare engagement and retention metrics across different departments or regions.
